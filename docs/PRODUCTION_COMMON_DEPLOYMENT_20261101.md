## 반영 범위

이 대화에서 변경한 공통 흐름/입력창, 한글 기본색·영문 청회색·한자 갈색, 기록·삭제 안내/경로, 공통 관리자 코드와 검수 프로필을 현재 개발 소스와 함께 운영 웹·서버에 반영했다.
기존 계정·서버·DB·키·OAuth 설정은 앱별로 유지했다. 환경파일을 교체하거나 DB를 초기화하지 않았다.
새 개인 계정 생성/탈퇴, 실제 데이터 삭제, 이메일 발송은 실행하지 않았다.

## 검증

- 새로 빌드한 정식 Web 채널과 공개 main.dart.js 해시 일치.
- 실제 HTTPS 공개 브라우저 390px/1280px, 한글 표시, 가로 넘침 없음, pageerror 0.
- health/readiness, account-deletion, data-controls, 권리 metadata, 미인증 관리자 차단, 숨김 환경파일 경로 확인.
- 전체 네 앱 합계 공개 endpoint 27개 PASS. 네 앱 웹 공개 브라우저 PASS.
- 배포 전 backend 전체 2,235개 통과 기록을 재사용했고, 별도 CI는 실행하지 않았다. 이번에는 실제 서비스 시작/의존성/공개 경로 검증을 추가했다.
- ONARIA/SORUA 웹의 한글 fallback 글꼴을 자체 포함했다. 외부를 차단한 로컬 화면에서도 한글을 확인했고, 공개 화면에서 이모지와 본문을 직접 확인했다. 일부 외부 로그인 SDK/이모지 fallback 요청까지 제거했다고 주장하지 않는다.
- 예전 Flutter 자산 캐시만 정리하는 worker를 배치했다. 브라우저의 사용자 설정/기록 저장소를 삭제하지 않는다.

## 운영 상태의 구분

공통 삭제 완료 확인기와 실제 운영 백업 증거 어댑터는 미연결이다. 해당 화면/API는 미확인 또는 완료 차단을 유지한다.
MAEON의 관리자·외부 AI·교리 자료 비활성 및 별도 회원 서비스 구조는 유지했다. 코드를 배포했다는 이유로 운영자 권한을 임의로 부여하지 않았다.
기존 콘텐츠 게시 경로를 공통 검수 큐로 자동 이관하거나 미승인 자료를 공개하지 않았다.
Android/iOS 설치와 App Store/Google Play 업로드·심사 제출·정식 공개는 **미실행**이다. 설치된 앱은 이 웹·서버 배포만으로 교체되지 않는다.
NAREUM Android Release 서명 설정 부재 등 앱별 스토어 준비 조건은 별도 해결해야 한다. 기존 서명키를 새로 생성하거나 교체하지 않았다.
commit/push는 하지 않았다. 이전 미커밋 사용자 작업은 보존했다.

## 배포 중 실패와 복구

MAEON 첫 패키지에서 backend 옆 content/ 디렉터리를 누락해 새 worker가 시작하지 못했다. 이전 코드의 재시작도 종료 실행기 상태 확인을 요구하여, 기존 보호 절차로 종료·미완료 작업 0건·DB 무결성·키 일치를 확인하고 복구했다.
수정 묶음은 실제 모듈 import graph와 복제된 저장소 생성 검사를 통과한 뒤 정상 배포했다. 실제 사용자 DB를 과거 백업으로 덮어쓰지 않았다.
첫 웹 교체 검사에서는 Nginx reload 직후 이전 worker가 반환한 파일 해시 불일치로 정적 배포를 되돌렸다. reload 반영 대기와 해시 재확인 후 최종 네 웹+MAEON 회원 테스트 웹을 검증했다.
이 이력을 숨기거나 최초 시도를 성공으로 표시하지 않는다. SORUA의 숨김 경로가 소개 페이지로 대체되던 응답도 404로 정리하고 템플릿에 반영했다.

## 되돌리기

비공개 백업의 코드/설정 또는 이전 릴리스 경로만 복구하고, 해당 앱만 재시작하여 health와 HTTPS를 검증한다.
운영 데이터·삭제 원장·키·환경파일을 과거 상태로 무조건 복사하지 않는다.
MAEON은 이전 executor 종료와 pending work 검사 및 기존 reviewed recovery 절차를 유지한다.


## 배포 후 관리자 인증 확인

실행 환경에 소유자 관리자 인증키가 설정되지 않은 것을 확인했다. 개별 관리자 계정의 존재·로그인은 이번에 조사하지 않았다. 공통 관리자 코드/화면 배포와 실제 관리자 로그인 사용 가능 여부를 구분하며, 관리자 운영 준비 완료로 표시하지 않는다. 자격 증명을 임의 생성하지 않았다.
