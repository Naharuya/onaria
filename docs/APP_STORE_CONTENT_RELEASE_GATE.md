- 기존 저장된 마음카드를 지우거나 덮어쓰지 않는다. 저장된 영어 구절은 기존 번역일 수 있으므로 내보내기 표시를 중립적인 `English`로 변경했다. 새로 제시하는 영어 말씀만 WEB이다.

- 사용자 확인: 첫 출시는 만 18세 이상 성인 대상이며 가입 시 확인한다. 실제 App Store 연령 등급 문답과 표시 설정은 별도 확인한다.
- 사용자 확인: 현재 무료 출시이며 앱 내 구매·유료 구독·결제 기능을 제공하지 않는다. 이용 안내에 반영했다.

- 기존 기기 기록에 저장된 NIV 내용은 보존했다. 배포 asset에서는 제거했지만 기존 데이터의 공유·낭독 권리까지 해결되었다고 표시하지 않는다.

## 현재 운영 설정의 읽기 전용 확인 (2026-10-07)

ari-prod-01의 `/opt/onaria/backend`, `onaria-backend.service` 실행 프로세스 환경과 `.env`의 비덮어쓰기 우선순위, 암호화 관리자 AI 설정의 우선순위를 확인했다. 파일 내용·키·토큰·회원 행은 출력하지 않았다. 서비스는 active이며 변경·재시작하지 않았다.

- 외부 API 차단=true, OpenAI 활성 요청=false, 유효 AI credential 없음, 실제 외부 AI 활성=false, embedding=local.
- 가명 사용량 원장=SQLite, 요청 정리 기준=62일. 이는 요청 처리 시 완료된 cost_requests를 정리하는 코드 기준이며 전체 테이블·로그·백업의 62일 자동 파기를 의미하지 않는다.
- 회원 세션 기본 유효기간=30일. 만료 세션의 활성 DB 정리와 백업 잔존 여부는 구분한다.
- OpenAI 지역은 현재 코드에 설정되어 있지 않다. 외부 AI를 활성화할 때 제공자·국가·보유조건·동의·스토어 고지를 별도로 확정해야 한다.

현재 외부 AI가 차단되어 있다는 사실을 모든 OS 로그인·음성·백업 처리에 국외이전이 없다는 보장으로 사용하지 않는다.

운영 메타데이터 추가 확인: ONARIA 이름의 systemd timer와 `/etc/logrotate.d/onaria`, `/etc/logrotate.d/onaria-backend`가 없고, 기본 journald.conf에 활성 SystemMaxUse/MaxRetentionSec 항목이 없다. 별도 이름의 cron·클라우드 백업·journald drop-in은 이번 검사 범위 밖이므로 백업이나 로그 보관이 없다고 단정하지 않는다. 전체 운영 로그·백업 보유기간은 여전히 미확정이다.
