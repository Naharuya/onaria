# 마음돌봄 공통 사용자 흐름

사용자 확정 2026-10-31. 대상은 ONARIA, NAREUM, maeon, 현재 SORUA다. 이전 philosophy 시안은 철학 제품 비교 대상에서 제외한다.

## 공통 순서

감정 확인 → 마음 대화 → 전통별 콘텐츠 선택/읽기 → 작은 실천 → 카드·기록.

1. 감정과 강도를 선택하고 대화로 전달한다. 기타 감정 입력에도 같은 안전 검사를 적용한다.
2. 대화는 해당 앱의 실제 제공 모드를 알린다. 로컬 안내를 실제 AI 답변으로 표현하지 않는다. 외부 전송은 기존 인증/동의 조건을 유지한다.
3. 대화 정상 종료 뒤에도 콘텐츠 선택 또는 콘텐츠 없이 실천으로 이어갈 수 있어야 한다. 콘텐츠 부족·조회 실패를 허구 인용으로 채우지 않는다.
4. 실천을 선택하면 감정·허용된 콘텐츠·실천 문맥으로 카드를 만든다. 콘텐츠를 건너뛴 카드에는 인용을 만들지 않는다.
5. 카드 저장 후 기록 화면으로 직접 이동할 수 있다. 미니게임과 공유는 선택 경로다. 기존 미니게임 저장 경로도 보존한다.
6. 위기 상태·처리 중·폐기된 화면은 일반 단계로 전환하지 않는다. 비동기 콘텐츠 조회 후에도 상태를 다시 검사한다.
7. 저장 실패는 실패로 알리고 기록 화면 이동을 하지 않는다. 재시도·삭제·계정 전환은 기존 앱별 저장 보호 규칙을 따른다.
8. 뒤로 가기/종료는 기존 화면 수명·음성 정지·개인 입력 정리를 유지한다.

## 유지보수 계약

각 저장소가 lib/care_flow.dart의 독립 사본을 소유한다. 계약 version=1과 다섯 단계 순서가 같고, 콘텐츠 표시는 앱별이다.
실행 시 다른 앱의 소스·파일·서버·DB·세션·키를 참조하지 않는다.
CareFlowProgress는 현재 위치만 표시하며 클릭으로 단계나 동의/안전 검사를 건너뛰지 못한다.
test/common_care_flow_test.dart 및 test/common_care_flow_navigation_test.dart로 계약과 실제 화면 전환을 검증한다.
향후 단계 변경 시 네 앱의 해당 계약/검증을 함께 대조한다. 앱 고유 콘텐츠·브랜드·안전/권리 기준을 공통화로 약화하지 않는다.

## 정확한 완료 범위

공통 사용자 동선은 AI 제공 방식, 로그인 활성 상태, 서버 저장, 콘텐츠 승인, 기기별 영속 보관을 동일하게 만든다는 뜻이 아니다.
기능이 이미 연결된 앱을 초기 시안으로 되돌리지 않는다. 가톨릭 외부 AI·운영 로그인·DB 수집을 이번 동선 수정으로 활성화하지 않는다.
코드/자동 시험, 로컬 빌드, 운영 배포, 실제 기기, 스토어 등록본을 각각 구분해서 보고한다.

## 비교 보고서 정정

2026-10-31 이전 비교 보고서의 철학 열은 /philosophy 초기 시안을 조사했다. 현재 SORUA는 이미 감정·대화·사유·실천·카드/기록 경로를 가진다.
따라서 철학의 '질문 선택→생각 입력'을 현재 SORUA의 상태로 사용하지 않는다.
네 앱이 전혀 다른 흐름으로 확정되었다는 해석도 정정한다. 공통 골격은 상당 부분 존재했고 종료 후 연결·저장 경로·표시·검증 형식을 이번에 맞춘다.

감정·강도·상황·원하는 도움·이미 답한 내용과 예시 보존은 [공통 맞춤대화 계약](COMMON_PERSONALIZATION_20261031.md)을 따른다. 기본 단계 통일과 맞춤대화 품질 검증을 구분한다.

## 카드 버튼·선택형 게임 공통 기준 (2026-11-01)

카드의 저장·공유·종료 버튼은 전체 너비, 최소 높이 48, 버튼 사이 최소 12 논리 픽셀을 유지하고 큰 글자에서 높이가 늘어난다. 앱 고유 게임으로 가는 선택 버튼을 카드 화면에 제공하며 게임을 하지 않고 저장·기록으로 이동하는 경로를 보존한다. 게임에서 돌아와도 작성 중인 카드를 유지한다.

## 마음대화 입력창 공통 기준 (2026-11-01)

입력창·마이크·보내기 화살표를 하나의 연한 외곽선으로 감싼다. 비입력 상태에서 약 10 CSS mm(38 논리 픽셀)의 조금 진한 선이 외곽을 순환하며, 입력 포커스가 생기면 즉시 숨긴다. 실제 물리 길이는 기기 밀도에 따라 다를 수 있다. 백그라운드·동작 줄이기에서는 애니메이션을 멈춘다. 음성 수집·AI·계정 기능 활성 상태는 앱별 기존 조건을 유지한다.
