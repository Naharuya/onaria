# 콘텐츠 게시 공통 기준 — 2026-11-01

초안 등록 → 권리 확인 → 검수 → 독립 최종 승인 → 게시 → 철회를 공통 적용한다. 모든 전이는 앱 식별자·본문ID·종류·버전·SHA256에 묶고 작성자/검수자/최종 승인자의 분리를 요구한다. 기존 공통 검수 기록만으로 게시를 허용하지 않는다.

기존 공개 파일과 정확히 일치하는 배포 기준본은 existing_distribution으로 보존한다. 신규 전문가 검수나 권리 확인을 완료한 것으로 표시하지 않는다. 파일이 바뀌면 기존 허용 해시를 재생성하여 우회하지 않고 새 검수 절차를 따른다.

| 앱 | 별도 검수와 배포 조건 |
|---|---|
| ONARIA | 번역본·원문·권리 표기를 함께 해시에 포함. 서버 추천 ID와 공개 본문 모두 게시 허용 목록으로 제한 |
| NAREUM | 기존 출처·권리·교리 검수에 공통 독립 승인을 추가. 온라인 검증된 공개 항목만 노출; 미검증 오프라인 경전 대체 없음 |
| MAEON | Catholic 원문/출처와 한국어 AI 번역 초안의 상태를 보존. 전문·교회 승인으로 표시하지 않음. 교리·AI 응답·운영 관리자 기존 제한 유지 |
| SORUA | 성찰 문구와 연결된 철학 원문을 한 검수 단위로 묶음. 철회된 항목은 추천과 원문 메타데이터에서도 제외 |

공개 API는 미승인·본문 변조·철회 항목을 제외하고 승인 증명만 반환한다. 검수자 개인정보와 비공개 증빙은 공개 응답에 포함하지 않는다. 조건부304도 승인 상태 확인을 건너뛰지 않는다.

새 클라이언트는 본문 해시와 앱 식별자, 유효기간을 매번 확인한다. 기존 서버 수신 허용 목록이 새 번들 목록을 완전히 대체하여 철회된 항목이 번들로 살아나지 않게 한다. 공개 철회 수신 상태는 공개 캐시에 보관하고, 손상·읽기 실패 때는 번들 허용을 되살리지 않는다. 사용자 대화나 기록은 이 캐시에 넣지 않는다.

오프라인 허용 상한: 원문 인용·AI 번역 초안7일, 독립 창작30일. NAREUM은 온라인 전용이며 증명은5분 이내다. HTTP304는 기간을 연장하지 않는다. 이미 오프라인인 기기·구버전·공유 사본의 즉시 회수를 보장하지 않는다. 폐기된 버전으로 롤백하면 철회 차단이 사라질 수 있으므로 실제 운영 철회 이후에는 승인 차단을 유지한 수정 버전으로 복구한다.

운영 게시 상태 DB는 앱마다 별도 파일·권한600으로 보관한다. 운영에서 사라지거나 손상된 DB를 빈 DB로 자동 초기화하지 않는다. 최초 배포 때만 명시적으로 새 파일을 준비하고, 이후 requireExisting으로 누락을 차단한다. 복구는 별도 검증된 게시 상태 백업에서 수행하며 계정 DB를 임의 복원하지 않는다.

삭제 요청 완료는 종류별 실제 증거를 요구한다. 회원탈퇴: 신원·세션·연결 제공자·백업보호; 서버 기록 삭제: 신원·백업보호; 동의 철회: 신원·동의 갱신·기존 데이터 처리 확인. 미연결 처리/백업 증명은 UNVERIFIED로 유지한다.

구현·자동 검증·운영 배포·스토어 제출·사람의 전문 검수는 별개의 상태다. 이 문서만으로 운영/스토어/전문 검수 완료를 주장하지 않는다.
