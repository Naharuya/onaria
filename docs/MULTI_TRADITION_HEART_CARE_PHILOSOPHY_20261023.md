# 다섯 전통의 마음돌봄 서비스 — 공통 철학 기록

- 기록일: 2026-10-23
- 상태: 철학적 방향 기록 / 브랜드·기능 확정 아님
- 범위: 기독교 ONARIA, 가톨릭, 불교, 철학, 향후 정의할 다섯 번째 전통

## 생각의 출발
인스타그램에서 LAM, VAM, RAM, YAM, HAM, OM 만트라 소리를 듣고 마음이 편안해지는 경험을 했다. 이 소리들이 각각 다른 이름처럼 들리면서도 하나의 흐름을 이루는 것처럼, 서로 다른 종교와 철학이 인간의 마음을 돌본다는 공통 방향을 가진다는 통찰로 이어졌다. 만트라의 종교적 의미를 각 서비스에 그대로 대응시키거나 차용하려는 뜻은 아니다.

## 공통 철학
> 우리가 걷는 길은 서로 달라도, 그 길 위에 있는 사람의 마음은 모두 소중합니다.

사람은 각자의 믿음과 사유 속에서 상처, 불안, 외로움, 희망, 삶의 의미를 마주한다. 종교와 철학은 서로 다른 전제와 궁극적 목적을 갖지만, 사람의 고통과 삶의 질문을 다루는 접점이 있다.

## 서비스 원칙
1. 서로 다른 종교를 하나의 교리로 합치지 않는다. 각 전통의 정체성, 용어, 상징, 콘텐츠 검수 체계를 존중한다.
2. 기독교 ONARIA는 기독교 마음돌봄 전문 브랜드로 유지한다. 가톨릭·불교·철학·기타 전통은 독립된 서비스와 브랜드로 기획한다.
3. 공통 기술과 안전 기반은 검토 후 재사용할 수 있으나, 저장소·배포·데이터·권한은 프로젝트별 독립 원칙을 따른다.
4. 기술보다 사람이 중심이다. 대화 전 호흡·묵상·기도·알아차림 등은 각 전통에 적합하게 별도 설계하며 강요하지 않는다.
5. AI는 성직자, 수행 지도자, 상담사, 의료 전문가를 대신하지 않는다. 심리적·종교적 안전성을 우선한다.
6. 만트라 소리의 편안함은 개인적 경험으로 존중하되, 특정 진동·주파수의 치료 효과를 과학적 사실처럼 주장하지 않는다.

## 분야별 방향(초안)
- 기독교 ONARIA: 말씀, 믿음, 마음돌봄
- 가톨릭: 기도, 묵상, 성찰
- 불교: 알아차림, 자비, 내려놓음
- 철학: 질문, 사유, 자기 이해
- 다섯 번째 분야: 특정 종교·영성 전통을 검토한 후 고유 정체성 정의

## 후속 과제
- 각 서비스의 고유한 철학과 사용자 경험 정의
- 공통 철학과 개별 브랜드의 관계를 설명하는 1페이지 원칙문 작성
- 종교별 콘텐츠·표현 검수 및 안전 정책 설계
- 브랜드명은 별도 상표 검토 후 결정
