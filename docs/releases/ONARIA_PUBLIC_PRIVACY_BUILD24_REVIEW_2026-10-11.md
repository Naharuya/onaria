# Build24 공개 개인정보 고지 보완안

운영 공개 고지를 읽기 전용으로 대조했다. 이 문서는 배포되지 않은 검토안이며 최종 보유기간을 임의로 확정하지 않는다.

## 추가할 소셜 로그인 설명

네이버·Google·카카오·Apple 로그인은 선택한 제공자의 인증 서비스와 SDK를 사용합니다. ONARIA는 회원 인증에 로그인 제공자와 계정 식별자를 사용합니다. 선택 입력한 이름·전화번호·교회명은 ONARIA 회원 DB에 보관됩니다.

Google 로그인 SDK는 이름·이메일·전화번호·사용자 및 기기 식별자·대략적인 위치·기타 사용 데이터와 기타 데이터를 앱 기능 또는 분석 목적으로 처리한다고 배포 개인정보 매니페스트에 선언합니다. 이는 ONARIA가 기기의 정밀 위치 권한을 요청하거나 회원 DB에 이메일·위치를 저장한다는 의미가 아닙니다. 카카오 인증 SDK는 기타 데이터를 앱 기능 목적으로 처리한다고 선언합니다. 로그인 제공자의 데이터 처리와 보유조건은 해당 제공자의 정책도 적용되므로 자사 회원 DB 처리와 구분해 안내해야 합니다.

Build24에 포함된21개 매니페스트는 tracking false 및 tracking domains 없음으로 선언합니다. 이는 광고 추적 선언의 근거이며 모든 네트워크 동작에 대한 실측 증명은 아닙니다.

## 계정 구조

로그인 제공자별 가입 계정은 별도로 유지됩니다. 이름·전화번호 일치만으로 자동 통합하지 않습니다. 기존 로그인 수단 연결과 서로 다른 기존 회원의 통합은 구분됩니다. 회원통합은 현재 운영 서버에서 제공하지 않습니다.

## 제출 전에 해결할 운영 사실

- 활성 회원 및 동의 기록: 계정 유지와 탈퇴 후 삭제 실제 범위 확인.
- 세션: 기본 유효기간과 만료 후 물리 정리 실행 여부 확인.
- 사용량: 원장 보유 설정과 pending/finished/abandoned 실제 정리 범위 확인.
- 프록시 및 서비스 로그: 실제 항목·보유기간·순환 실행 증거 확인.
- 백업: 생성 위치·복사본·최장 보유기간·탈퇴 후 복원 방지·파기 실행 증거 확인.
- 플랫폼/SDK 처리 및 국외 처리: 확인된 제공자·실제 데이터 흐름을 기준으로 고지. 외부 AI 비활성으로 소셜 플랫폼의 모든 해외 처리가 없다고 주장하지 않음.

SDK 설명만 추가하고 로그·백업의 미확정 기간을 확정됐다고 쓰지 않는다. 운영 적용 및 재시작은 기존 HOLD 범위다.
