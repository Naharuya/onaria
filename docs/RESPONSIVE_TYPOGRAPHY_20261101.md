# 공통 반응형 글자 크기 — 2026-11-01

ONARIA, NAREUM, MAEON, SORUA의 Flutter 앱과 Flutter 웹에 동일한 DeviceTextScaler/ResponsiveTypography를 적용한다. 별도 HTML 관리자 페이지의 글자 크기는 이번 변경 범위에 포함되지 않는다.

## 동작
- 논리 화면의 짧은 변을 기준으로 한다. 가로 회전과 키보드 등장으로 휴대폰이 태블릿 배율로 전환되지 않는다.
- 390dp에서 기존 크기, 600dp에서 +6%, 900dp 이상에서 최대 +12%로 연속 보간한다.
- 320dp 이하에서 큰 제목만 최대 6% 축소하며, 20sp 이하 본문/라벨은 축소하지 않는다.
- 플랫폼 TextScaler에 기기 배율을 합성한다. 사용자 접근성 배율을 고정/상한 처리하지 않으며 비선형 확대를 보존한다.
- 중첩 래퍼는 배율을 중복 적용하지 않는다. 기존 MediaQuery의 inset, 시스템 패딩 등 다른 값은 보존한다.
- MAEON의 기존 개인정보 보호 래퍼를 유지한다. 기존 언어별 색상과 앱별 테마도 유지한다.

## 검증과 한계
공통 단위/위젯 테스트는 화면별 배율, 본문 최소 크기, 비선형 접근성 확대, 중첩 적용, 키보드 inset 보존, 가로 회전 시 동일 배율을 확인한다. 대화 흐름/탐색/입력창 회귀와 변경 파일 분석 결과는 동반 JSON을 따른다.

별도 고정 TextScaler/MediaQuery override가 있는 하위 위젯은 자체 설정이 우선한다. 이 변경만으로 모든 화면/모든 접근성 배율의 overflow 부재를 보장하지 않는다. 실기기, 브라우저 시각 점검, native/web release 빌드 및 운영 반영은 검증 JSON에 각각 구분한다.

콘텐츠 승인 절차 변경은 별도 진행 중이며 이 타이포그래피 검증을 서버 승인/게시/철회 기능의 검증 결과로 사용하지 않는다.
