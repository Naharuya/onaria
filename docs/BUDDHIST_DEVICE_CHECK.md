## 한계와 정리

- 이번 실기기 검사에서 위기 문구 입력 및 위기 시 예약/음성 중단 전체 시나리오는 NOT RUN. 이전 자동 Safety 테스트를 이번 실기기 통과로 간주하지 않는다.
- 알림 거절 안내에 음성 관련 설명도 함께 표시되는 기존 공통 오류 문구는 개선 여지가 있다. 예약 성공으로 오표시되지는 않았다.
- 화면 검증 동안 USB 연결 시 화면 유지 설정을 임시 적용했으며 검사 후 원래 값 0으로 복원 확인. 잠금 인증/글자 크기/회전 설정 변경 없음.
- 검증용 합성 카드 1개는 앱에 남겨 두었다. 앱을 마음 화면으로 돌려놓았다. 알림 권한은 사용자가 앱을 테스트할 수 있도록 허용 상태다.
- 이전 코드 검증: Buddhist 57 PASS, analyze clean, Christian 집중 4 PASS. 이번에는 코드 변경이 없어 재실행하지 않았다. BUILD/Christian 전체 회귀/CI/운영 API: NOT RUN, 실기기 확인 범위이며 push 보류.
- 실제 경전 수집·저장·라이선스 승인·운영 변경·키 변경 없음. 외부 후보는 계속 BLOCKED_EXTERNAL_REVIEW이며 응답/검색/마음카드에 사용하지 않는다.

이 기록은 이전 보고서의 잠금으로 미확인된 항목 중 위 표에 명시한 항목만 보완한다. 전체 개발 종료 조건을 모두 통과했다는 선언이 아니다.
