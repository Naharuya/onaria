# 원문·번역 언어 색상 공통 적용

2026-11-01 사용자 확정: 한글은 기본 글자색을 유지하고 영문·한자는 은은한 색 차이로 구분한다.

- 대상: ONARIA / NAREUM / MAEON / SORUA의 말씀·가르침·철학 원문과 번역, 읽기 화면과 저장 카드 상세. Flutter 컴포넌트를 공유하는 각 Web 앱에도 같은 규칙을 적용한다.
- 한글과 숫자·구두점·기타 문자는 기존 DefaultTextStyle 및 화면별 style을 상속한다. 특정 먹색으로 고정하지 않는다.
- 영문/라틴 문자: 밝은 배경 #526F82, 어두운 배경 #9BB4C6를 시작 색으로 사용한다.
- 한자: 밝은 배경 #87684E, 어두운 배경 #C6AA8B를 시작 색으로 사용한다. 확장 한자·호환 한자와 결합 기호/이체자 선택자를 보존한다.
- 두 강조색은 현재 Material surface 및 surfaceContainerHighest와 대조하여 대비 4.5 이상이 되도록 onSurface 방향으로 필요한 만큼만 보정한다. 배경은 새로 바꾸지 않는다.
- 원래 글자·띄어쓰기·줄바꿈·단락·글자 크기·기울임·선택·복사·언어 제목을 유지한다. 원문/번역/AI 초안/출처 및 검수 표시를 제거하지 않는다.
- 메뉴, 입력창, 계정·안전 안내, 사용자와 AI의 대화 말풍선, 전송·저장 데이터와 음성 낭독에는 일괄 색상 처리를 하지 않는다. 공유 이미지 생성기는 이번 화면 변경 범위에 포함하지 않는다.
- lib/language_text.dart는 각 독립 저장소가 자체 소유한다. 다른 앱의 런타임 파일·계정·API·키를 참조하지 않는다.

## 검증과 반영 단계

밝은/어두운 배경의 대비, 한글 기본색 상속, 원문 문자열 일치, 확장 한자·이모지 보존, 선택 가능한 본문과 글자 확대를 테스트한다. 기존 앱별 읽기·기록 흐름 회귀도 실행한다. 실제 실행 결과는 language-colors-verification-20261101.json을 따른다.

코드 적용과 TEST 빌드는 기기 설치·운영 Web 배포·스토어 제출 완료가 아니다. 기존 기록·삭제·회원탈퇴 공통 계약과 출시 검증 상태는 그대로 유지한다. 이전 DATA_RIGHTS_REVIEW의 색상 미적용 항목은 당시 제안 기록이며 이 문서가 후속 적용 현황이다.
