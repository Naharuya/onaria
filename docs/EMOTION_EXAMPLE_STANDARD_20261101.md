# 감정 카드·대화 예시 공통 기준 — 2026-11-01

## 사용자 확정 동작
네 앱의 기존 감정 카드/대화 답변 예시를 원문 그대로 합치고 감정 카드에 맞춰 제공한다. 대화 중 예시 버튼은 한 번에 5개다. 선택한 문구는 해당 대화의 후보에서 제외하고 다음 문구로 보충한다. 새 대화에서 선택 이력은 초기화한다. 위기 안내/응답 대기/종료 화면은 예시 표시보다 기존 Safety 흐름을 우선한다.

## 공통 목록
`common_emotion_examples.dart`를 네 저장소가 동일하게 소유한다. 16개 감정에 배정한 항목은 총244개이며 놀람·벅찬17개, 나머지 감정15개다. 공통 대화 예시는342개, 기존 템플릿2개다. 이 수는 분류별 항목 수로, 감정/대화 분류 사이 중복을 제거한 고유 문장 수를 뜻하지 않는다.

`emotion-example-union-20261101.json`은 이전 문구, 통합 목록과 출처를 기록한다. 문장부호·띄어쓰기가 다른 원문을 임의 수정하지 않는다. 동일 문장은 각 목록에서 한 번만 보인다. 경전/교리 본문, 마케팅·게임 설명, 실천 지시문, 사용자 실제 대화는 이 답변 예시 합본 범위와 구분한다.

## 표시와 보충
- 첫 질문: 선택 카드와 강도에 맞는 공통 문구, 해당 카드의 개인 주제 예시를 우선한다.
- 후속 질문: 현재 질문에 맞는 기존 답변 예시를 우선한다. 질문이 바뀌면 그 질문의 목록으로 갱신한다.
- 부족한 자리는 질문 주제별 문구와 ‘아직 모르겠어요/천천히 생각하고 싶어요’ 같은 중립 응답으로 보충한다. 모르는 시간·장소·색상 등을 임의 추정하지 않는다.
- ConversationExampleDeck가 대화별 선택 이력을 관리한다. 모두 보기에서도 선택한 문구를 제외한다. 원문 목록 자체는 삭제하지 않는다.

## 반복 핵심 단어 → 개인 주제 카드·예시
`PersonalKeywordLearning`은 외부 API/모델/파일/Preferences를 사용하지 않는다. 직접 제출한 안전한 문장에 포함된 고정 일상 주제 ID와 횟수만 이번 앱 사용 중 메모리에 둔다. 원문을 새로 보관하거나 서버·다른 앱·다른 사용자에게 공유하지 않는다.

업무·학업·가족·친구·관계·휴식·미래·비교·일상·도전·감사·기대의12개 주제를 대상으로 회사/직장→업무, 시험/공부→학업 같은 표현을 합친다. 한 문장의 동일 주제는1회, 별도 직접 입력3회부터 카드에 추가한다. 예시 버튼 선택·위기 입력은 횟수에 포함하지 않는다. 이름·연락처·질병명 등 임의 단어를 새 카드 제목으로 승격하지 않는다. 새 감정 진단을 만들지 않으며 ‘자주 쓰는 주제’로 표시한다.

관련 예시는 검토된 고정 템플릿에 주제명만 넣는다. 감정별 예시에 사용할 때는 실제 관찰한 감정과 주제의 연결을 따른다. 첫 화면에서 추가 기능을 끄거나 추가된 주제와 예시를 지울 수 있다. 기능을 끄면 누적값도 지운다. ONARIA/NAREUM/SORUA는 기록 접근 범위가 바뀌면 사용을 차단하고 누적값을 지운다. MAEON은 FlowSession clear/dispose 시 지운다. 앱 재실행 후 유지하는 영구 학습 기능은 이번 구현에 포함하지 않는다.

기존3개 앱의 EmotionCardStore에 이미 저장된 카드는 보존한다. 기타 입력30회 승격 경로의 신규 쓰기는 중지하며, 새 자동 추가는 직접 입력3회/이번 사용 중 기준을 따른다. 개인 주제 카드 선택과 예시 선택은 영구 누적하지 않는다.

## 검증/배포 구분
소스 보존, 카드별 선택,5개 보충과 선택 문구 제외, 개인 주제3회 승격·비정상/예시 입력 제외·계정 범위 변경·끄기/지우기를 단위/위젯 테스트한다. 실제 화면 보충과 기존 대화/Safety/탐색 회귀를 별도로 수행한다. 이번 검증이 콘텐츠 게시 승인, 운영 배포, 스토어 제출 또는 실기기 설치의 증거를 대신하지 않는다. 실행 결과는 동반 검증 JSON에 기록한다.
