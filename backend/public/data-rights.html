ONARIA 계정과 기록 관리

기록 삭제와 회원탈퇴는 서로 다른 작업입니다. 이 페이지는 ONARIA 계정만 대상으로 하며 다른 앱의 계정과 자료를 삭제하지 않습니다.

저장 위치

기기 카드·실천·여정·초안과 서버 회원정보는 별도 관리합니다.

웹의 로컬 기록은 현재 브라우저에 남습니다. 기기 기록이 서버에 자동으로 복사되거나 다른 기기와 동기화된다고 가정하지 마세요.

1. 개별 기록 삭제

내 기록에서 삭제할 카드를 선택하고 삭제 범위를 확인합니다. 삭제한 기록은 복원할 수 없습니다.

2. 이 기기의 내 기록 전체 삭제

앱 또는 웹 메뉴 → 계정과 기록 관리 → 이 기기의 내 기록 전체 삭제에서 진행합니다. 현재 사용하는 계정 또는 비회원 기록만 삭제하며 회원 계정·서버 기록·다른 계정과 소유자가 확인되지 않은 이전 기록은 유지합니다.

3. 서버 기록 삭제

별도로 서버에 저장한 기록은 서버 기록 관리 화면에서 삭제합니다. 기기 기록 삭제나 앱 삭제만으로 서버 기록이 삭제되지 않습니다. 서버 저장을 제공하지 않는 실행 모드에서는 이 항목을 사용하지 않습니다.

4. 회원탈퇴 · 계정과 연결 데이터 삭제

홈 메뉴의 계정 관리에서 회원탈퇴를 선택할 수 있습니다. 계정 소유 확인 없이 전화번호나 회원번호만으로 삭제하지 않습니다.

앱 메뉴 → 계정과 기록 관리 → 회원탈퇴에서 시작하고 본인 확인 후 삭제합니다. 탈퇴 시 이 앱의 서버 계정, 연결 로그인 식별자, 유효 세션 및 계정에 연결된 개인 데이터를 삭제합니다. Apple 로그인이 연결된 경우 Apple 본인 확인과 토큰 해제 절차를 진행합니다. 소셜 제공자 자체 계정은 삭제하지 않습니다.

처리 실패·통신 중단·결과 미확인 시 완료로 표시하지 않습니다. 탈퇴 완료와 남은 기기 정리·백업 처리는 구분해 안내합니다. 사용 중인 서비스의 보관 항목·기간·예외·파기 절차는 개인정보 안내에서 확인하세요.
